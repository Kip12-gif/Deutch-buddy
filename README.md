# 🇩🇪 DeutschBuddy — English to German Learning App

An interactive Streamlit web application designed for learning German through instant translation, native text-to-speech pronunciation, formality switching (*Du* vs. *Sie*), and grammar breakdowns.

## Features
- **Instant English → German Translation**
- **Native German Audio Pronunciation** via Google TTS
- **Formality Selector** (*Informal Du* vs. *Formal Sie*)
- **AI Grammar & Noun Gender Breakdown** (*der / die / das*)
- **Interactive Flashcard Deck** saved during your session

## Run Locally
```bash
git clone [https://github.com/YOUR_USERNAME/deutsch-buddy.git](https://github.com/YOUR_USERNAME/deutsch-buddy.git)
cd deutsch-buddy
pip install -r requirements.txt
streamlit run app.py
